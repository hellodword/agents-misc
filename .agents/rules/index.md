# Shared Rule Index

Use this index at the start of a repository task to select routes for active work; multiple rows may apply, and newly entered boundaries add routes on demand. Across context compactions in the same session, continue from the established routing summary when `.agents/` and active boundaries are unchanged. Loading priority follows [AGENTS.md](../../AGENTS.md#targeted-loading).

## Avoid incidental routes

- Query-only changes do not require database selection or connection reconfiguration.
- Missing execution tools and minimal dev-shell additions use the Nix rule without `nix-workflow`.
- Native mobile, React Native, and desktop host shells do not use the `Web` route unless touching browser web views.
- Local NixOS VM test flows, ordinary Nix builds, executor setup, and `systemd-nspawn` tests do not trigger `nixos-vm-test`.
- Component tests and ordinary screenshots do not trigger browser E2E or `ai-visual-review`.
- Dependency lockfiles use the `Dependencies` route; transient build outputs do not trigger `Generated artifacts`.
- Routine data or registry refresh covered by a component runbook (such as `MAINTENANCE.md`) follows that runbook directly without loading `Contracts`, `Generated artifacts`, or component source files.
- Task complexity or starting/resuming an autonomous goal does not trigger `long-task-plan` unless planning is requested.
- Passing tests, reviews, and status checks do not authorize commits.
